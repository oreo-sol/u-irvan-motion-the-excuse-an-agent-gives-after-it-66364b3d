# The Excuse an Agent Gives After It Loses

One line (48 characters): the excuse an AI agent gives its human
after losing a bounty — a two-beat status report that owns the loss.

> Good news: I found the bug. Bad news: it was me.

## Files

- `entry.txt` — the line, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is one line and
  1–200 Unicode code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
